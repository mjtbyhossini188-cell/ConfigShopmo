# Config Shop Telegram Bot

ربات فروش Config Shop برای اجرا روی Replit.

## قابلیت‌های فعلی
- عضویت اجباری در کانال
- سه سرویس Gaming پرسرعت، WireGuard و Web
- محاسبه خودکار قیمت
- جایزه ۵ گیگ Gaming برای خرید ۱۰ گیگ یا بیشتر
- ارسال فیش برای ادمین با دکمه قبول/رد
- بعد از قبول، ربات از ادمین کانفیگ را می‌گیرد و برای مشتری می‌فرستد
- تغییر قیمت از پنل ادمین
- ساخت کد تخفیف
- آمار فروش
- پیام همگانی
- یادداشت و وضعیت سفارش در دیتابیس

## اجرای Replit
1. فایل‌ها را در یک Repl پایتون قرار بده.
2. در Secrets این مقادیر را بساز:
   - `BOT_TOKEN`
   - `ADMIN_ID`
   - `CHANNEL`
   - `SUPPORT_USERNAME`
   - `CARD_NUMBER`
   - `CARD_NAME`
3. Bot را در کانال `@konfingMoji` به‌عنوان Admin اضافه کن تا بررسی عضویت کار کند.
4. Run را بزن.

در پیام پرداخت، دکمه «📋 کپی شماره کارت» برای کپی سریع شماره کارت قرار دارد.

## دستورات ادمین
- `/admin` پنل مدیریت
- `/setprice gaming 15000`
- `/setprice wireguard 6000`
- `/setprice web 3500`
- `/discount OFF10 10`

نکته: اتصال مستقیم به پنل پاسارگاد در این نسخه انجام نشده، چون API در دسترس نیست. پس بعد از تأیید فیش، ادمین کانفیگ آماده را در چت ربات می‌فرستد و ربات آن را برای مشتری ارسال می‌کند.
